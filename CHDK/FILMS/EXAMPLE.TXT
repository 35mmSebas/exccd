# --------------------
# Copy this file to A/CHDK/FILMS/FILMS.TXT and edit it.

# "Off" always comes first and does not belong in the file.

#   Mode    Canon My Colors: 0 = Off, 1 = Vivid, 2 = Neutral, 3 = B/W,
#           4 = Sepia, 5 = Positive film, 11 = Custom Color

#           red, green, blue, skin tone), only used with mode 11
#   Curve   file in A/CHDK/CURVES, name max. 7 characters, - = none.
#           Dynamic+ uses <name>1.CV and <name>2.CV.
#   Label   picture A/CHDK/FILMS/<label>.FLM, max. 8 characters, - = text card
