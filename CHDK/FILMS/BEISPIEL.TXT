# Eigene Filmtabelle
# ------------------
# Diese Datei nach A/CHDK/FILMS/FILMS.TXT kopieren und anpassen.
# Sie wird beim Einschalten gelesen. Ohne FILMS.TXT gilt die eingebaute
# Tabelle (sie entspricht genau dieser Datei).
#
# Eine Zeile je Look, Spalten mit | getrennt. Zeilen mit # sind Kommentare.
# "Aus" steht immer an erster Stelle und gehoert nicht in die Datei.
# Max. 24 Looks.
#
#   Name    max. 20 Zeichen, ohne Umlaute
#   Modus   Canon My Colors: 0 = Aus, 1 = Lebhaft, 2 = Neutral, 3 = S/W,
#           4 = Sepia, 5 = Positivfilm, 11 = Custom Color
#   Kon Sch Sat R G B Haut
#           Custom-Color-Regler -2..+2 (Kontrast, Schaerfe, Saettigung,
#           Rot, Gruen, Blau, Hautton), wirken nur bei Modus 11
#   Kurve   Datei in A/CHDK/CURVES, Name max. 7 Zeichen, - = keine.
#           Fuer Dynamik+ werden <Name>1.CV und <Name>2.CV benutzt.
#   Lasche  Bild A/CHDK/FILMS/<Lasche>.FLM, max. 8 Zeichen, - = Textkarte
#   Mix     RAW-Kanalmischung: 0 = keine, 1 = Lila-Effekt, 2 = Entsaettigt
#           (Spalte darf fehlen)
#
# Fehlerhafte Zeilen werden uebersprungen und in A/CHDK/FILMS/FILMS.LOG
# aufgelistet.
#
